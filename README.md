# cat-life-workspace

喵星驻地球办事处 · 个人生活数据工作台

把日程、习惯、饮食、运动、书影音、理财、专注与实时资讯收进一个页面，数据全部存在本地。

## 在线体验

- GitHub Pages：`https://tzmlyy-lgtm.github.io/cat-life-workspace/`
- 支持「添加到主屏幕」，像 App 一样全屏使用，离线也能打开

## 功能

| 模块 | 说明 |
| --- | --- |
| 综合首页 | 今日待办聚合、日程统筹、番茄钟、全屏时钟、一日总结、便利填写 |
| 每日灵感 | 随手记录与回顾 |
| 英语口语 | 29 个雅思高频话题，每日推送三题，中英语音跟读 |
| 减脂饮食 | 31 条常见食物热量表，录入自动换算当日摄入与剩余 |
| 运动塑形 | 运动打卡、习惯养成（打卡/计数 + 近 7 天点阵）、睡眠体重趋势 |
| 热点新闻 | 3 个公开数据源实时抓取，逐个降级 + 离线兜底 |
| 书影音 | 书 / 影 / 乐三类记录，状态、星级、颜色标记、影评 |
| 理财存钱 | 收支流水、月度预算与消耗进度 |
| 我的树洞 | 心愿、带里程碑的目标、好友生日倒数、待买清单、碎碎念（可附图） |

## 技术要点

- **单文件零依赖**：`life-workspace.html` 内联全部 CSS / JS / SVG，双击即可使用，也可直接挂任意静态托管
- **本地数据层**：基于 localStorage 命名空间 `cw_<账户>_*` 承载 16 个数据域，支持多账户隔离与访问密码、旧数据自动迁移、JSON 导出导入备份
- **番茄钟**：自定义时长、自动循环多轮、全屏专注、结束响铃与振动；使用记录带任务维度，状态跨模块持久化（存「阶段结束时刻」而非已流逝秒数，恢复时精确反算剩余）
- **多源数据抓取**：3 个公开资讯源逐个降级，字段统一归一化、去 HTML 标签清洗，本地缓存 + 定时刷新 + 页面回焦补刷，断网自动回退内置数据集
- **PWA**：Service Worker（页面网络优先、静态资源缓存优先），可安装到主屏、离线可用，状态栏颜色随主题配色联动
- **视觉体系**：6 套配色 × 明暗双主题，CSS 变量三级覆盖；水彩纸质感背景（SVG feTurbulence 颗粒 + 笔刷扫痕 + 颜料晕染）
- **微信小程序端**：`cat-workspace-miniprogram/`，6 个页面

## 关于开发方式

这是一个 **AI 原生开发实践**：需求定义、架构取舍与验收标准由我制定，AI 承担代码实现、内容数据集结构化与接口可行性探测。

为保证 AI 产出可信，自建了一套回归断言作为质量闸门——用 Node `vm` 沙箱 + 最小 DOM 桩覆盖 12 组场景（模块渲染、计时器状态机、数据落盘、跨模块状态接回、任务维度等），任何改动必须全量通过才合入。

```bash
node tools/smoke-test.js   # 12 组回归断言
node tools/news-check.js   # 新闻源可达性与解析验证（需联网）
```

## 本地运行

直接用浏览器打开 `life-workspace.html` 即可（`file://` 下 PWA 注册会自动跳过）。

需要验证 PWA 安装与离线能力时，用任意静态服务器起一个 http 环境：

```bash
cd deploy-site && python -m http.server 8080
```

## 部署

推送到 `main` 后由 GitHub Actions 自动部署 `deploy-site/` 到 GitHub Pages，见 `.github/workflows/deploy-pages.yml`。
