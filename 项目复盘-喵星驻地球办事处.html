一、项目目标与背景

背景：用户肖雯（中央民族大学 应用统计学 大二，北京，求职方向数据分析/运营）需要一个能统一管理日常生活的个人工作台——把日程、习惯、健身、财务、目标、灵感等分散在多个 APP 的记录，收敛到一个地方，降低记录门槛、提升坚持度。

产品定位：「喵星驻地球办事处」——一个温暖治愈的泛生活一站式工作台。以漫画猫咪 + 奶油色系为视觉语言，让"记录"这件事本身变得轻松可爱。

技术定位：单文件 HTML、零依赖、数据本地存储（隐私优先）、电脑/手机浏览器同一文件自适应；并逐步衍生出微信小程序版、资料库在线同步版，以及面向分享的介绍页与小红书文案。

为何这样定位：纯前端单文件意味着"双击即用、不联网、不注册、数据只存自己设备"，对注重隐私又不想被复杂工具劝退的个人用户最友好；同时单文件也最易于转发和二次修改。

二、我与 AI 的分工

🧑 你（肖雯）：产品决策与验收

  • 提出功能需求与方向（美化 / 拖拽 / AI 总结 / 小程序 / 介绍 / 小红书）
  • 用「截图 + 一句话指令」反馈视觉与 Bug（如猫咪马赛克、图标巨大化）
  • 定义审美偏好：奶油色、漫画猫咪、简洁、界面美观度要求高
  • 决定产出形态与时间节奏，对每次迭代做最终验收

🤖 AI（WorkBuddy）：工程实现与执行

  • 前端代码编写与多轮迭代（HTML/CSS/JS，单文件）
  • 猫咪素材处理：去马赛克、透明背景化（Pillow）
  • 数据聚合逻辑：AI 一日总结的本地智能归纳算法
  • 部署（CloudStudio 稳定链接）、微信小程序工程搭建
  • 测试与 Bug 修复（node --check + 隔离函数 smoke test）
  • 小红书文案与配图建议、介绍页生成

协作模式：你做"导演 + 测试员"，AI 做"工程师 + 文案"。需求以截图和极简指令下达，AI 直接出可运行成果，你再截图反馈微调——形成"指令 → 实现 → 反馈"的快速闭环。

三、核心挑战与解决方案
挑战解决方案结果
猫咪素材带马赛克 / 不透明背景Pillow 中性色检测（|r-g|、|g-b| 均 <10 且亮度>178）→ alpha 置 0；纯像素循环去马赛克（numpy 不可用）15 张透明漫画猫，无残留背景
浏览器缓存致"猫咪仍有马赛克"所有图片引用加 ?v=2 缓存破坏参数，重新部署刷新即生效，视觉问题消除
网页端 SVG 灯泡图标巨大化占满屏根因：.ic 尺寸约束只在 .card h3 .ic 内；一日总结/便利填写的 h3 不在 .card 内 → 新增通用 .ic{width:18px;height:18px}图标恢复正常尺寸
侧栏导航文字重复（"综合首页 综合首页"）根因：NAV_ICONS 值里同时含 SVG+文字，renderSidebar 又拼接了 label span → 移除 NAV_ICONS 内冗余文字，只留 SVG每项只显示一次，渲染正确
AI 一日总结需大模型但无后端 / 密钥改为纯前端「本地智能聚合」：规则化读取当日日程/习惯/随手记/支出/目标，生成自然语言复盘，零依赖离线可用一键生成个性化总结，可复制
资料库共享链接权限拒绝（code 12607）无法克隆他人模板 → 从零自建「学习目标管理台」：3 张表（目标/打卡/周复盘）+ 4 个 Tab，资料库 SDK 在线同步跨设备在线数据，已发布
微信小程序需原生工程手写 wxml/wxss/js/json 共 44 文件，TabBar 导航 + wx.setStorageSync 本地存储开发者工具可直接导入预览
小红书爆款数据 API（红狐）未配置降级：基于公开检索趋势（萌宠陪伴型习惯 App 走热）+ 小红书通用爆款结构创作，诚实标注未用实时库拿到可直接发布的文案 + 配图建议
多轮迭代 CSS/JS 一致性风险每次改动后跑 node --check 语法校验 + 隔离提取关键函数做 fake-DOM/smoke 测试交付前均验证通过，无回归

六、后续可优化方向

1️⃣ 跨设备备份：当前网页数据存浏览器 localStorage，换设备/清缓存会清空。可加「导出/导入 JSON」一键备份，弥补本地存储短板。

2️⃣ 小红书文案升级：配置 REDFOX_API_KEY 后，可将文案升级为基于小红书实时爆款笔记数据（含互动数据）的精准版本。

3️⃣ 秒哒一键 APP：在 miaoda.cn 获取 API Key 配置后，可一键生成 Web/App 版本，触达更多端。

4️⃣ 能力沉淀：将"单文件 HTML 工作台迭代 + 透明猫咪素材处理 + 小红书降级创作"等可复用流程沉淀为 Skill，下次同类需求直接调用。
